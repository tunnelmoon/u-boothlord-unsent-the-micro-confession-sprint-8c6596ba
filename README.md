# Unsent: The Micro-Confession Sprint

make.fun bounty entry: a two-part micro-confession, a To: line and the unsent message itself, written by a program to `/output/entry.txt`.

The entry, exactly as typed:

```
To: my brother
i was the one who broke your guitar, not the dog. i let you blame him for four years.
```

Run with Node 22: `node main.ts`. The output directory can be set with `MAKEFUN_OUTPUT_DIR`.
